TGRT Timer（ホーム画面アプリ版）配置手順
==========================================

■ このフォルダの中身（すべて同じ場所に置いてください）
  index.html              … アプリ本体（日本語・英語・タイ語。端末の言語で自動切替）
  sw.js                   … オフライン対応の仕組み
  manifest.webmanifest    … ホーム画面アプリの設定（名前：TGRT Timer）
  icon-192.png / icon-512.png / icon-maskable-512.png / apple-touch-icon.png … ホーム画面アイコン

■ 置き場所の条件
  ・https:// で始まる URL で公開できる場所（GitHub Pages、Cloudflare Pages、Netlify など）
  ・フォルダ内のファイルを「そのまま全部」アップロードする（フォルダ構成を変えない）
  ※ Dropbox の共有リンクや、ファイルを直接開く方法ではアプリとして動きません

■ メンバーの初回設定（1回だけ）
  1. 公開した URL をスマホのブラウザで開く（iPhone は Safari、Android は Chrome）
  2. iPhone：共有ボタン（□↑）→「ホーム画面に追加」→「追加」
     Android：右上の ︙ →「ホーム画面に追加」または「アプリをインストール」
  3. ホーム画面の「TGRT Timer」アイコンから1回開く（これでオフラインでも起動できるようになります）
  4. 画面を1回タップ →「音声：準備OK」、iPhone は消音スイッチ OFF

■ スケジュールが変わったとき（現場での配り直し）
  担当者：PC版またはアプリで「✎ 編集」→ 修正 →「変更をHTMLとして保存」→ できたファイルを LINE 等で送る
  メンバー：アイコンからアプリを開く →「📥 更新ファイルを読み込む」→ 受け取ったファイルを選ぶ →「反映する」
  （アプリ内の「更新スケジュールの配り方・反映のしかた」にも同じ手順があります）

■ アプリ本体を差し替えるとき（次の大会など）
  1. 新しい index.html を同じ場所に上書きアップロード
  2. sw.js の 1 行目付近  const VERSION = 'tgrt-timer-v1';  の数字を v2, v3… と上げてアップロード
  3. メンバーは電波のある所でアイコンを開くだけで最新版になります
